UVM Full Adder Verification

This project demonstrates verification of a Full Adder using SystemVerilog UVM.

Features:
- UVM testbench architecture
- Transaction-based stimulus
- Driver and Monitor implementation
- Scoreboard checking DUT correctness
- Functional coverage for input combinations
- Assertions verifying sum and carry logic
- Simulation in QuestaSim

Coverage Achieved: 96.88%
Assertions: Passed
